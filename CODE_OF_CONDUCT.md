# Code of Conduct

## Our Pledge

We aim to make DELTREE a practical and respectful open-source project for people building Apple-platform developer tools.

Participants are expected to:

- Be direct, constructive, and respectful.
- Assume good intent while still being precise about technical problems.
- Keep discussions focused on reproducible behavior, safety, privacy, and maintainability.
- Avoid harassment, personal attacks, and disclosure of private information.

## Enforcement

Maintainers may edit or remove comments, close issues, block participants, or take other reasonable action when behavior undermines a productive project environment.

To report a concern, use the security/contact channel in [SECURITY.md](SECURITY.md) if private handling is required, or open a GitHub issue for normal project conduct problems.
